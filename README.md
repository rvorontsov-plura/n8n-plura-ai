# n8n-nodes-plura-ai

n8n community node for [Plura.ai](https://plura.ai) - build, deploy, and manage AI agents for calls, chat, and workflows.

## Features

**Trigger:**
- Automation Triggered - receives webhook events when Plura.ai automation nodes execute

**Actions:**
- Get Lead by Phone / ID
- Update Lead
- Send Lead to Workflow
- Add / Remove Tag
- Initiate Call

## Installation

```bash
npm install n8n-nodes-plura-ai
```

Then restart n8n. The node will appear in the node panel.

## Credentials

Enter your Plura.ai account email and password. Optionally provide an API key for direct API access.
